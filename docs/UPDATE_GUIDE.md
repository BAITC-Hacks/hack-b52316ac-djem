# Обновление интерфейса на уже развёрнутом сервере

## Что меняется

Эта итерация обновляет только веб-интерфейс и инструкции. Затронуты `static/index.html`, `static/app.js`, `static/style.css`, `HANDOFF_FOR_AI.md` и этот файл. Backend, API, зависимости Python, схема SQLite, `.env` и формат сохранённых сценариев не меняются. Миграция базы данных не требуется.

## Перед обновлением

1. Сохраните резервную копию базы. Для обычного запуска используйте `python backup_db.py`. Для Docker следуйте разделу резервного копирования в `DEPLOY_BREV.md`.
2. Зафиксируйте копию текущих трёх файлов из `static/` или снимок папки проекта.
3. Не заменяйте серверный `.env`, каталог `data/`, папку `backups/` или Docker volume с базой.

## Обновить существующий Python-запуск

Из распакованной поставки скопируйте поверх старых файлов только:

```text
static/index.html
static/app.js
static/style.css
```

Перезапуск FastAPI обычно не нужен: он читает статические файлы при запросах. Откройте сайт с принудительным обновлением страницы (`Ctrl+F5`). В HTML также обновлена версия URL для CSS и JavaScript, поэтому браузер запросит свежие файлы.

## Обновить Docker Compose

Перенесите три файла интерфейса поверх файлов существующего проекта, оставив его в той же папке с тем же Compose project name. Затем из этой папки выполните:

```bash
docker compose up -d --build
```

Проверьте `docker compose ps` и `/health`. Существующий именованный volume базы останется подключённым, если используется прежнее имя Compose-проекта. Не запускайте `docker compose down -v`: этот параметр удаляет volume с данными. Не распаковывайте проект в новую папку и не меняйте имя Compose project без проверки, какое имя volume использует текущая база.

## Проверка после обновления

1. Перезагрузите страницу и убедитесь, что появился текущий экран брифинга.
2. Начните миссию, выберите пять допустимых мер, проверьте суммы бюджета и выполните расчёт.
3. Проверьте краткий итог. Если OpenAI не настроен, должен отображаться честно подписанный разбор расчётной модели.
4. Откройте «Показать детали плана», затем снова скройте их и начните новую миссию.
5. Проверьте сохранённые сценарии и настройки оператора: существующие записи должны остаться на месте.

## Откат

Верните сохранённые `static/index.html`, `static/app.js` и `static/style.css` или восстановите прежний релиз. Схема и содержимое базы этой итерацией не меняются, поэтому откат интерфейса не требует обратной миграции.

Подробная инструкция по первому развёртыванию находится в `DEPLOY_BREV.md`.
