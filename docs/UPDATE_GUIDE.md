# Обновление объединённой версии

Архив `akim-merged-update.zip` содержит актуальные исходники проекта. `.env`, базы, логи, резервные копии и виртуальное окружение не включены. Его можно распаковать поверх установленного проекта.

## Через Jupyter на Brev

Загрузите ZIP в `/home/ubuntu`, затем откройте Jupyter → File → New → Terminal. ZIP не нужно открывать как текст: сообщение «not UTF-8 encoded» означает лишь неверный способ открытия архива.

Выполните:

```bash
cd /home/ubuntu/akim-python
.venv/bin/python backup_db.py
mkdir -p backups
python3 -m zipfile -c backups/static-before-merged.zip static
cd /home/ubuntu
python3 -m zipfile -e akim-merged-update.zip akim-python
cd akim-python
bash deploy/restart_brev.sh
curl -fsS http://127.0.0.1:8080/health
```

Затем откройте публичный сайт и нажмите Ctrl+F5. Сохраните нынешний `.env`, каталог `data/` и `backups/`. Скрипт перезапуска останавливает только процесс этого проекта из `logs/app.pid`; если прежний процесс запущен иначе, он сообщит об этом, не завершая неизвестный процесс.

Для установки из Git: `git pull --ff-only`, затем тот же скрипт перезапуска. При локальных правках сначала сохраните их: не используйте принудительный сброс.

## Если уже установлена версия с библиотекой результатов

Серверная часть и схема БД в этой UX-итерации не изменились. Достаточно заменить **пять** файлов: `static/index.html`, `static/app.js`, `static/style.css`, `static/missions.js`, `static/api-response.js`. Последние два — новые модули, их нельзя пропускать. При нативном запуске после этого достаточно Ctrl+F5. Полный архив также подходит.

Вариант друга с заменой только трёх статических файлов относится к его старой поставке и для объединённой версии недостаточен.

## Docker

Перед обновлением сделайте копию через `docker compose exec app python backup_db.py` и скопируйте полученный файл из контейнера на хост согласно `DEPLOY_BREV.md`. После замены исходников из той же папки проекта выполните:

```bash
docker compose up -d --build
```

Сохраните `.env` и именованный том с базой. Не выполняйте `docker compose down -v`: это удаляет том.

## Проверка

1. `/health` возвращает `{"status":"ok"}`; без входа доступен обзор.
2. После входа инструменты и «Мои результаты» находятся на главной.
3. Выберите миссию, соберите пять решений, нажмите «Завершить и рассчитать».
4. Проверьте цель, расходы, сводку, раскрытие деталей и презентацию.
5. Перезагрузите страницу: план, миссия и итог сохраняются.
6. Внешний AI проверьте с вашим ключом; численная модель работает и без него.

## Откат этой UX-итерации

При нативном запуске восстановите прежние статические файлы:

```bash
cd /home/ubuntu/akim-python
python3 -m zipfile -e backups/static-before-merged.zip .
```

Новые неиспользуемые модули можно оставить. Обновите страницу Ctrl+F5; для Docker пересоберите контейнер. БД откатывать не нужно: UX-итерация не меняет её схему. Эта инструкция относится к откату с объединённой версии на предыдущую версию с аккаунтами и библиотекой, а не на старый проект из архива друга.
