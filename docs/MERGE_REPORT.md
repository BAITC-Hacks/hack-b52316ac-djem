# Выборочное объединение artur.zip / artur2.zip

Дата: 23 сентября 2026.

Сопоставлены оба архива, переданный текст и текущая версия проекта с аккаунтами и библиотекой результатов. `artur2.zip` содержит более позднюю UX-итерацию; основой остаётся текущий FastAPI + SQLite проект.

## Перенесено и адаптировано

- Три миссии: качество жизни, баланс районов и подготовка к паводку. Цель проверяется по серверному прогнозу и исходным условиям той же миссии.
- Итог с достижением цели, Score, эффектом решений, расходами, остатком, критическими показателями и слабейшим районом.
- Кольцевая диаграмма расходов по направлениям; суммы рядом доступны без восприятия цвета.
- Наиболее влиятельная мера и компромисс. Маржинальные эффекты не выдаются за складываемые вклады.
- Компактная итоговая сводка, раскрытие деталей и начало новой миссии. Миссия и состояние сводки включены в существующее персональное автосохранение.
- Сворачиваемые сведения о мерах, событии и дополнительных действиях; основная кнопка завершения расчёта.
- Состояния загрузки, устаревшего прогноза и повторного расчёта. Неудачная смена события сохраняет прежние условия, план и результат.
- Доступный индикатор бюджета, мобильная вёрстка, обновлённые версии ресурсов.
- Инструкция обновления/отката и адаптированный сценарий выступления.
- Обработка HTML-страниц вместо JSON с указанием неудачного API-запроса. Это улучшение диагностики, а не подтверждение устранения причины на внешнем прокси.

## Сохранено из текущего проекта

Гостевая главная, авторизация и роли, база аккаунтов, личные черновики, библиотека результатов, инструменты на главной, сохранённые презентации, контуры районов, цепочки влияния, подробный AI-разбор, редактор данных, аудит и версии.

Серверные исходники, формулы Score, схема БД, зависимости, seed и данные из архивов друга не заменяют текущие. Уже имевшиеся сохранение района и защита от запоздалых ответов сохранены и объединены с новыми состояниями интерфейса.

## Проверено локально

- 20 существующих тестов Python; проверки JS для условий миссий и ответов API.
- Синтаксис JavaScript.
- Вход, миссия, ручной выбор пяти мер, расчёт 57,24 при расходе 9,8 млрд ₸, сводка, детали и восстановление после обновления страницы.
- При тестовой ошибке смены события план и Score остаются прежними; после тестовой ошибки прогноза доступен повтор расчёта.
- Ширина 390 px: сводка и план без горизонтального переполнения.
- Новая миссия с паводком и инструменты на главной.

Проверки интерфейса проведены на отдельной локальной тестовой БД, без реальных вызовов OpenAI. Реальный AI ранее проверялся в текущем проекте; эта итерация не меняет его серверную интеграцию. Публичный сервер автоматически не обновляется при изменении GitHub или создании архива.
