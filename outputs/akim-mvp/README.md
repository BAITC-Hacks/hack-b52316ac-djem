# Аким на 5 часов · MVP

Рабочий веб-прототип симулятора распределения городского бюджета.

## Запуск

Требуется Node.js 20 или новее. В каталоге проекта выполните:

```powershell
npm start
```

Откройте `http://localhost:4173`.

Для сетевого хостинга задайте `HOST=0.0.0.0` и проксируйте порт через HTTPS. По умолчанию сервер слушает только локальный компьютер.

## Настройка ИИ-сводки

Без API-ключа сайт формирует локальный аналитический разбор по правилам. Чтобы получать короткий текст от модели, задайте переменную окружения `OPENAI_API_KEY` до запуска сервера. Ключ хранится только на сервере и не попадает в браузер. Модель можно переопределить через `OPENAI_MODEL`; по умолчанию используется `gpt-6-astra`.

Для локального запуска можно скопировать `.env.example` в `.env` и заполнить ключ. Файл `.env` сервер читает при старте и не раздаёт клиентам.

## Что реализовано

- Фиксированный бюджет **100 млрд ₸** для каждой сессии.
- Пять направлений: транспорт, озеленение, социальная сфера, безопасность, городские сервисы.
- Изменение одной доли автоматически перераспределяет остаток между другими статьями, сумма всегда сохраняется.
- Итоговая круговая диаграмма, балл из 100 и сравнение с целевым профилем игрового сценария.
- Короткий ИИ-разбор при настроенном ключе. Без ключа работает локальный резервный анализ.

## Важно про оценки

Сценарий «Рост новых районов» и его целевой профиль (25%, 15%, 25%, 15%, 20%) придуманы для демонстрации механики. Они не являются утверждённым бюджетным советом или оценкой реального качества жизни. Для публичного запуска Astana Innovations должна согласовать сценарий, метрики, веса и причинные правила.

Сессии не сохраняются в базе. Сервер получает только распределение бюджета и вычисленные показатели. Если настроен OpenAI API, эти числовые данные отправляются API для генерации краткой сводки. Не добавляйте в запросы персональные данные игроков.

## Развёртывание

Запускайте `npm start` на сервере с Node.js 20+, настройте переменную `PORT` (по умолчанию 4173) и включите HTTPS через ваш хостинг или reverse proxy. Для реального публичного доступа нужен выбранный сервер или хостинг и домен.
