# Аким на 5 часов — Python и база данных

Идёт перенос симулятора на FastAPI + SQLite. Датасет хакатона сохранён в seed/dataset.json.
Рабочие данные будут храниться в БД с версиями, прогнозы — рассчитываться сервером,
AI-агент — вызывать инструменты чтения и изменения через авторизованный API.

Все суммы представлены в тенге. Начальный условный масштаб: 1 единица исходного
кейса = 1 млрд тенге. Это перевод синтетической модели, не оценка рыночных затрат.

Секреты задаются только в локальном .env или окружении сервера. Файлы БД и .env
исключены из Git. Полная инструкция развёртывания на NVIDIA Brev будет в DEPLOY_BREV.md.
